# AstroTaca Downloads

Software guides and downloads for AstroTaca Flat Panel.

## Get started

Start with the [one-page quick start](manual/QUICK-START.md), or use the
[software guide](manual/README.md) for connection, NINA, calibration, opening
limits and button brightness.

For printing: [Quick start PDF](manual/AstroTaca-Flat-Panel-Quick-Start.pdf) |
[Software guide PDF](manual/AstroTaca-Flat-Panel-Manual.pdf).

## Downloads

No installer has been published here yet. Installers, release notes and checksums
will appear under [Releases](https://github.com/astrotaca/AT-Downloads/releases).

The Windows installer includes the AstroTaca ASCOM driver and control app.
If ASCOM Platform is needed, Setup helps you install it. Panel firmware updates
have separate instructions.

## Help

[Report a software problem](https://github.com/astrotaca/AT-Downloads/issues/new?template=software-problem.yml)
or [ask a question](https://github.com/astrotaca/AT-Downloads/issues/new).
Include your software version, the exact error and what you were doing.
Reports are public, so remove personal information from screenshots and logs.
