# AstroTaca Downloads

Official software downloads and update instructions for AstroTaca flat panels.

**Software is currently in development. No public download is available yet.**
Tested packages and installation instructions will be published here when ready.

## Downloads

Visit [Releases](https://github.com/astrotaca/AT-Downloads/releases) for published
installers, firmware updates, release notes and checksums.

The planned Windows installer will include the AstroTaca ASCOM driver, control
app and diagnostics. The ASCOM Platform will be a prerequisite. Users will not
need Arduino IDE, Python or developer tools.

Firmware updates will have their own instructions and compatibility information.
Use only a package listed for your AstroTaca product and follow its update guide.

## Support

[Open an issue](https://github.com/astrotaca/AT-Downloads/issues) for software
questions or bug reports. Include your AstroTaca product, software version,
Windows version and what happened. Remove personal information before sharing logs.

This repository distributes end-user software and documentation. Product design
files and development source code are not included.
